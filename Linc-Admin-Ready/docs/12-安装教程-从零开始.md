# 12 · 安装教程（从零开始 · 开箱即用版）

> 面向零基础用户：从**新购买一台空白云服务器**开始，到打开浏览器使用后台，每一步都有可复制的命令。全程约 30-60 分钟。
>
> **你手里这个版本什么都不缺**：PHP 依赖（vendor/）和前端页面都已内置，不需要 Composer，不需要 Node.js，跟着做就行。
>
> 你的装备清单：一台云服务器（推荐 2 核 4G 起）、一个域名（可选，IP 也可直接访问）、一台能上网的电脑。

---

## 第 1 步 · 准备服务器（约 10 分钟）

### 1.1 购买云服务器

任选一家国内云厂商（阿里云 / 腾讯云 / 华为云等）：

1. 产品选择 **云服务器 ECS / 轻量应用服务器**；
2. 地域选离你最近的（如华东 / 华北）；
3. 配置建议：**2 核 CPU、4G 内存、40G 系统盘** 起（演示环境 1 核 2G 也能跑）；
4. 操作系统选 **CentOS 7.9 / Alibaba Cloud Linux / Ubuntu 22.04** 均可（本文以 CentOS / 通用 Bash 为例）；
5. 设置 root 登录密码（或密钥对），记下来；
6. **安全组 / 防火墙放行端口**：`22`（SSH，默认开）、`80`（HTTP）、`443`（HTTPS）。宝塔面板安装后还会用到 `8888`（面板）。

### 1.2 连接服务器

Windows：用「终端 / PowerShell」执行 `ssh root@你的服务器IP`，或使用厂商网页版终端；macOS / Linux 直接 `ssh root@IP`。输入密码后看到欢迎信息即成功。

### 1.3 （强烈推荐）安装宝塔面板

宝塔是免费的中文服务器管理面板，图形化装好 PHP / MySQL / Nginx，是新手的最短路径：

```bash
# CentOS / Alibaba Cloud Linux
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec

# Ubuntu / Debian
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
```

安装完成会打印**面板地址、用户名、密码**（形如 `http://服务器IP:8888/xxxxxx`），抄下来。若云厂商有「轻量应用服务器·宝塔镜像」，直接选镜像可跳过本步。

> 浏览器打不开面板地址？回云控制台安全组放行 `8888` 端口。

---

## 第 2 步 · 安装运行环境（约 10 分钟）

登录宝塔面板，首次进入会让你装 LNMP 环境：

1. 环境 choose **Nginx**（任意新版本）+ **MySQL 5.7**（必须 ≥ 5.7；8.0 也可）+ **PHP 8.1**（或 8.2），选「极速安装」，等待 5-15 分钟；
2. 装完后：宝塔左侧 **软件商店 → PHP 8.1 → 设置 → 安装扩展**，确保 `pdo_mysql` 已安装（通常默认有）、`fileinfo` 建议安装；
3. 记下 MySQL 的 root 密码：宝塔 **数据库** 页面右上角有 root 密码提示（或自行修改为你记得的值）。

> 不用宝塔的进阶用户：手动安装 PHP 8.1+（含 pdo_mysql、zlib）、MySQL 5.7+/8.0、Nginx，效果等同，见《06 配置与部署》的纯 Nginx 配置。

---

## 第 3 步 · 上传源码（约 5 分钟）

### 3.1 获取源码

两种方式任选：

- **GitHub 下载**：仓库页 Code → Download ZIP，解压后取其中的 **`Linc-Admin-Ready`** 文件夹（仓库里还有一个 Dev 版文件夹，小白部署用不到它）；
- **Git**：`git clone` 整个仓库后同样只取 `Linc-Admin-Ready` 子目录。

### 3.2 上传到服务器

- **宝塔方式（推荐）**：宝塔左侧 **文件** → 进入 `/www/wwwroot/` → 上传压缩包 → 右键解压，得到 `/www/wwwroot/Linc-Admin-Ready`；
- **命令行方式**：本机 `scp -r Linc-Admin-Ready root@服务器IP:/www/wwwroot/`。

> 这个版本自带 `vendor/`（PHP 依赖）和已构建好的前端页面，服务器**不需要安装 Composer，也不需要 Node.js**。

---

## 第 4 步 · 创建站点（约 5 分钟）

宝塔左侧 **网站 → 添加站点**：

| 表单项 | 填写 |
| --- | --- |
| 域名 | 你的域名（如 `admin.example.com`，需先在域名解析里加一条 A 记录指向服务器 IP）；没有域名就填服务器 IP |
| 根目录 | `/www/wwwroot/Linc-Admin-Ready` |
| PHP 版本 | 8.1 |
| 数据库 | 不勾选（稍后用安装向导创建） |

创建后进入 **站点设置 → 网站目录**：

1. **运行目录**选 `/public`，保存；这一步是安全关键——让 Web 只暴露 `public/`；
2. **伪静态**：下拉选 `laravel5` 模板保存即可（它就是「静态资源优先、其余转 index.php」）。

> 非宝塔用户：按《06 配置与部署》§6.4 的 Nginx 配置照抄（把 `server_name` 与 `root` 换成你的）。

---

## 第 5 步 · 运行安装向导（约 5 分钟）

1. 浏览器打开 `http://你的域名`（或 IP）：
   - 看到灵枢中控**安装向导**即成功；如果显示 404/空白，回到第 4 步检查运行目录与伪静态；
2. **第一步 环境检查**：全部通过点「下一步」；有不通过项按提示处理（通常是目录权限：宝塔文件管理里把 `runtime/` 和 `config/` 权限改为 755 并在站点设置里解除跨站，或 `chown -R www:www`）；
3. **第二步 数据库连接**：

   | 表单 | 填写 |
   | --- | --- |
   | 数据库地址 | `localhost`（MySQL 与网站同机） |
   | 端口 | `3306` |
   | 数据库名 | 自定义，如 `linc_admin`（不存在可勾选「自动创建」） |
   | 账号 / 密码 | 宝塔 **数据库** 页面 root 信息，或先在宝塔「数据库」里建一个库+账号再填 |
   | 会话时区 | 国内保持 `+08:00` |

   点「测试连接」，提示连接成功后进入下一步；
4. **第三步 管理员账号**：设置登录后台的账号与密码（默认 `admin / admin123`，**生产环境务必改强密码**）；存储方式保持「文件存储」即可（无需 Redis）；
5. **第四步 执行安装**：几秒完成 → 点「进入登录页」。

> 数据库建在宝塔「数据库」页面时，账号密码就是该库的专属账号，权限更小更安全。

---

## 第 6 步 · 登录使用（约 2 分钟）

1. 用安装时设置的管理员账号登录；
2. 默认「灵枢青」主题（DevUI 风格）；喜欢玻璃质感去左侧「主题中心」一键切换，浅色 / 深色在顶栏「外观设置」；
3. 建议**立即做三件事**：
   - 顶栏头像 → 修改密码；
   - 「用户管理」停用或删除演示账号 `chensy`、`wumin`；
   - 「参数配置」检查 `sys.user.initPassword`（新用户初始密码），改为你的规范。

---

## 第 7 步 · 上线加固（生产环境必读）

| 事项 | 做法 |
| --- | --- |
| HTTPS | 宝塔 **网站 → 设置 → SSL**：Let's Encrypt 一键申请，开启「强制 HTTPS」 |
| 数据库备份 | 宝塔 **计划任务**：每天备份数据库 + 网站，保留 7 天 |
| 面板与端口安全 | 修改宝塔面板端口与入口路径；安全组只放行 80/443，SSH 改密钥登录 |
| 验证安装锁 | 确认 `runtime/install.lock` 存在；不要删除它（否则安装接口重新暴露） |
| 会话安全 | 多机部署/重启频繁的生产环境，把 `config/config.php` 的 `cache.driver` 改为 `redis`（宝塔软件商店装 Redis 即可） |
| 域名备案 | 国内服务器绑定域名需完成 ICP 备案（云厂商控制台有流程） |

## 第 8 步 · 本机体验（不用服务器）

只想先看看效果？本地装 PHP 8.1（Windows：[php.net 下载](https://www.php.net/downloads) 或 phpstudy；macOS：`brew install php`）+ MySQL 5.7，然后：

```bash
cd Linc-Admin-Ready
php -S 127.0.0.1:8090 -t public public/index.php
# 浏览器打开 http://127.0.0.1:8090，向导中数据库填本机 MySQL 信息
```

## 常见安装问题速查

| 现象 | 处理 |
| --- | --- |
| 打不开面板/网站 | 云安全组没放行对应端口 |
| 安装向导说目录不可写 | 宝塔文件管理改 `runtime/`、`config/` 权限为 755，属主改为 www |
| 「数据库连接失败」 | 账号密码错误；或 MySQL 未启动；远程库需放行来源 IP |
| 页面样式丢失 / 刷新 404 | 运行目录不是 `public/`，或伪静态未配置 |
| 装完想换库 | 删除 `runtime/install.lock` 与 `config/config.php`，刷新重装 |

更多问题见《09 常见问题 FAQ》；部署细节（Nginx 手写配置、Redis、多机）见《06 配置与部署》。
