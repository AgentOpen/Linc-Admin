# 13 · 使用手册（管理员操作指南）

> 面向后台日常使用者：每个页面做什么、怎么操作、有哪些规则。安装与部署见《12 安装教程（从零开始）》，二次开发见 Linc-Admin-Dev 版的《05 扩展开发实战》。

## 1. 登录与账号

- 打开系统地址，输入账号、密码和右侧验证码；勾选「记住登录状态」后本机 2 小时内免重复登录；
- 登录后进入**工作台**；无任何菜单权限的账号会看到「暂未分配菜单」提示，联系管理员分配；
- 顶栏右上角头像：**修改密码**（旧密码校验，6-64 位）、退出登录；
- 会话过期（默认 2 小时）后任意操作会提示重新登录，登录后自动回到原页面。

## 2. 工作台

登录后的首页，一屏掌握系统动态：

- **登录脉搏**：近 24 小时 / 7 天 / 30 天登录量曲线，峰值、均值与上一周期对比；
- **读数卡**：用户总数、在线用户（近 1 小时登录）、角色数量、24h 接口调用（含环比）、菜单项、部门数；
- **当日泳道**：按模块聚合今天的操作，点击时间块可携带模块关键词跳到操作日志明细；
- **最近登录**：最近 8 条登录成功 / 失败记录。

## 3. 用户管理

维护后台账号，支持「列表」与「看板」两种视图（右上角切换）。

- **查询**：关键词（账号 / 姓名 / 手机号）+ 状态 + 部门树筛选；「导出」按钮导出当前条件的 CSV；
- **新增用户**：账号（唯一）、昵称必填；初始密码不填则使用参数 `sys.user.initPassword`（默认 `Yy@123456`）；可同时分配部门、角色、岗位；
- **编辑 / 停用**：看板视图把卡片拖到「停用」列即可停用（有确认）；停用账号立即无法登录；
- **重置密码**：行操作「重置密码」，输入新密码（6-64 位）；
- **保护规则**：内置管理员（id=1）不允许停用与删除。

## 4. 角色管理

- **角色列表**：名称、编码（唯一）、数据范围、状态、内置标记；
- **权限矩阵**：表格视图的矩阵中勾选「角色 × 菜单」，改动累计到底部浮条一次提交；**内置角色只读**；
- **数据范围**：编辑角色时选择——全部 / 本部门及以下 / 本部门 / 自定义（勾选部门）/ 仅本人；决定该角色用户在用户列表等数据中能看到谁；
- **保护规则**：角色已分配用户时不能删除；编码唯一。

## 5. 菜单管理

定义左侧导航与按钮权限，三层结构：目录（dir）→ 页面（menu）→ 按钮（btn）。

- 新增页面菜单：类型 `menu`、路由地址（如 `/biz/notice`）、组件标识（如 `biz/notice/index`，必须与前端 `COMPONENT_MAP` 登记）、权限标识（如 `biz:notice:list`）；
- 新增按钮权限：类型 `btn`，只需权限标识（如 `biz:notice:add`）；
- **保护规则**：存在子菜单、已分配角色的菜单不能删除；菜单 ID 自动递增；
- 菜单调整后，相关角色成员**重新登录**生效；超级管理员始终可见全部启用菜单，无需分配。

## 6. 部门管理

组织画布视图：树形组织结构平移缩放，选中部门时上级路径脉冲高亮。

- 新增部门必填名称；上级部门决定 `ancestors` 祖级链（影响「本部门及以下」数据范围）；
- **保护规则**：存在下级部门、部门下有用户时不能删除。

## 7. 岗位管理

列表 CRUD：岗位编码（唯一）、名称、排序、状态；「阶梯」视图展示岗位层级与各岗位人数；用户管理中为账号分配岗位（可多选）。

## 8. 字典管理

统一维护下拉选项：字典类型（如 `sys_user_sex`）→ 字典数据（标签 / 值 / 色调 / 默认项）。

- 业务下拉统一走「字典选项」接口，只需启用状态的选项，无需额外权限；
- **保护规则**：字典类型下存在数据时不能删除类型；数据项的 `tone` 决定前端标签颜色（info / ok / danger / purple / neutral…）。

## 9. 参数配置

系统运行参数（键值对），支持「面板」与「表格」两种视图；面板按前缀分组、行内编辑、底部浮条一次提交。

内置参数：

| 键 | 含义 |
| --- | --- |
| `sys.user.initPassword` | 新建用户的初始密码 |
| `sys.account.captchaEnabled` | 是否开启登录验证码 |
| `sys.index.appearance` | 默认外观（light / dark / auto） |
| `sys.login.alertThreshold` | 登录失败异常聚合阈值（默认 5，可新增此参数） |

**保护规则**：内置参数（builtin=Y）不可修改与删除。

## 10. 操作日志

横带三层：概览读数（总量 / 失败率 / 平均与 P95 耗时 / 活跃人数）→ 趋势或泳道 → 明细。

- 检索：关键词（模块 / 类型 / 操作人 / URL / 参数）+ 结果（成功 / 失败）；
- 请求参数中的 `password`、`token` 等敏感字段自动显示为 `******`；
- 支持单条删除与清空（需 `monitor:operlog:remove` 权限），清理前建议先导出 CSV 归档。

## 11. 登录日志

- 概览：总量、失败、人数、IP 数与趋势（24h / 7d / 30d）；
- **热力**：星期 × 小时的登录分布，失败占比高的格子有斜线标记；异常聚合列出「同 IP / 同账号失败达到阈值」的可疑行为（阈值可调）；
- 明细：账号、IP、浏览器 / 系统、结果与描述；同样支持导出与清理。

## 12. 代码生成

面向开发者的工具：把数据库表变成业务模块开发骨架。

1. **导入表**：从当前库选择表（系统表以外均可）导入；
2. **字段配置**：每个字段的列表展示 / 查询 / 必填 / 表单控件类型；保存说明；
3. **预览**：7 个文件——PHP 仓储 / 服务 / 控制器 / 路由注册片段 + 前端 API / 页面 + 菜单 SQL；
4. **下载 ZIP**：按包内路径放入项目对应目录，按 Linc-Admin-Dev 版《05 扩展开发实战》补全业务逻辑后接入。

## 13. 主题中心

为系统挑选外观皮肤：

- 卡片展示每套主题的迷你预览、版本、作者、特性标签；点击「使用此主题」立即生效并记忆；
- 出厂主题：**灵枢青**（默认，DevUI 风格）与 **珍珠玻璃**（玻璃拟态）；
- 顶栏「外观设置」可叠加调整：浅色 / 深色 / 跟随系统、表格密度（宽松 / 标准 / 紧凑）、侧栏折叠——对所有主题通用；
- 想要自己的主题？把需求交给开发，或参考 Linc-Admin-Dev 版《05 扩展开发实战》§5.2，30 分钟即可新增一套。

## 14. 全局交互技巧

- **命令面板**：顶栏「搜索菜单」或 `Ctrl+K`，快速跳转页面、执行常用动作，输入 `?` 可用内置问答（本地规则，不联网）；
- **快捷键**：`Esc` 关闭浮层；表单内 `Enter` 提交；
- **导出**：所有列表的导出为 UTF-8 CSV，Excel 打开如中文乱码，用「数据 → 自文本导入」选择 UTF-8 编码；
- **列表防错乱**：快速切换查询条件时旧结果不会覆盖新查询（请求序号机制）。

## 15. 遇到问题

- 先看《09 常见问题 FAQ》；
- 页面提示异常时，把提示中的追踪 ID（traceId）反馈给技术同事，可精确定位日志；
- 权限问题（菜单不见 / 按钮 403）：找管理员在「角色管理」重新授权后**重新登录**。
