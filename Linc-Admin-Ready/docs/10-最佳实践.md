# 10 · 最佳实践

## 10.1 上生产前检查清单

**安全**

- [ ] 安装向导中设置了强管理员密码（或安装后立即修改），删除不需要的演示账号（chensy / wumin）；
- [ ] `runtime/`、`config/` 不在 Web 可访问路径（运行目录 = `public/`），或 Nginx/Apache 已拒绝；
- [ ] HTTPS 启用，`X-Forwarded-For` 由可信代理传递；
- [ ] `app/.../AuthMiddleware::PUBLIC_PATHS` 未被随意扩大；
- [ ] 数据库账号遵循最小权限（日常运行账号不需要 DROP 库权限）。

**配置**

- [ ] `jwt.secret` 为安装器生成的随机值且多机一致；
- [ ] `database.timezone` 与业务时区一致；
- [ ] 高并发或多机部署已切换 `cache.driver = redis`；
- [ ] OPcache 开启（见《07》）。

**数据**

- [ ] 已做每日备份（mysqldump + binlog），并演练过恢复；
- [ ] 日志表归档策略已定（按月导出 CSV 清理）；
- [ ] 契约回归通过：`php tests/api_contract.php`。

## 10.2 二次开发的推荐节奏

1. **从复制最近的同类页面开始**：列表页抄 `Posts.vue`（最简 CRUD），树形抄 `Depts.vue`，设置面板抄 `Configs.vue`——项目内现成模式永远优先于自创写法；
2. **每个接口先在路由表落位**（权限码 + 操作日志），再写控制器——权限与审计是"登记制"，防止遗漏；
3. **文案即契约**：校验提示与错误文案写成业务中文，`tests/api_contract.php` 中补一条断言锁住它；
4. **前端不做后端能做的事**：分页、过滤、排序口径由后端统一，前端只负责呈现与交互；
5. **小步提交**：一个逻辑单元（表 + 接口 + 页面 + 菜单 SQL）完成即建议 commit，附 `changelog.md` 记录。

## 10.3 代码组织建议

| 场景 | 建议 |
| --- | --- |
| 多个模块共用的查询片段 | 收敛到对应 Repository 的私有常量 / 方法（如 `BASE` / `userWhere()` 模式） |
| 新的公共校验 | `app/Core` 增加助手函数（参照 `helpers.php` 的 `required()` / `trim_to_null()`） |
| 跨页面的前端状态 | `composables/` 新增文件（参照 `dict.ts` / `dept.ts` 的引用缓存模式） |
| 新的主题 | 严格按 Linc-Admin-Dev 版《05 扩展开发实战》§5.2 四步走，禁止在页面内写 `if (skin === ...)` |
| 定时任务 | 当前版本无常驻进程；用系统 cron 调 PHP 脚本（`php app/console.php` 风格自建入口）或数据库事件 |

## 10.4 主题与品牌

- 品牌统一改 `frontend/src/data/index.ts` 的 `APP` 对象（name / shortName / subtitle / copyright），全站标题、侧栏、登录页、命令面板随之更新；安装向导品牌在 `public/install.html`；
- 客户交付换肤时：优先做**令牌覆盖包**而不是改基线——升级版本时冲突最小；
- 保持"每页只有一个视觉主角"的设计纪律（见 `docs/设计规范.md`），新页面克制使用仪表化元素。

## 10.5 性能与容量

- 日志表超过百万行后：加时间索引收益递减，改为按月分表或归档（《07》）；
- 部门层级控制在 10 层内（`ancestors` 链式设计的安全边界）；
- 单角色菜单建议 < 200 条（前端菜单树渲染无虚拟化）；
- 导出 5000 行上限是刻意设计；更大需求走异步任务。

## 10.6 演进路线建议

- **多租户**：以 `tenant_id` 全表注入 + 数据范围扩展实现，Repository 的集中 SQL 让这一改动可控；
- **国际化**：后端文案集中在各 Service（中文硬编码），前端文案集中在组件与 `data/`；统一抽取为字典文件即可；
- **接口版本化**：`/api/v2/...` 在路由表新增分组，旧包络不变；
- **文件上传**：`sys_file` 表已预留，按 Linc-Admin-Dev 版《05 扩展开发实战》§5.1 模式补 Controller / Service / Repository 与上传校验。
