# 03 · 核心功能模块详解

## 3.1 安装器（PHP 版新增能力）

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/install/env` | GET | 环境检查：PHP 版本、`pdo_mysql`、`zlib`、`runtime/` 与 `config/` 可写、Redis 可用性（可选） |
| `/api/install/test` | POST | 测试连接：MySQL 版本 ≥ 5.7、库是否存在、是否已有系统表、能否自动建库 |
| `/api/install/run` | POST | 执行安装：建库 → 按版本号执行 `database/V*__*.sql` → 写入自定义管理员（BCrypt）→ 生成 `config/config.php`（含 64 位随机 JWT 密钥）→ 写 `runtime/install.lock` |
| `/api/install/status` | GET | 安装状态查询 |

- 安装向导 UI 在 `public/install.html`，与后台同一设计语言；
- 已安装后再访问安装接口返回 **403「系统已安装」**；重新安装需删除 `runtime/install.lock` 与 `config/config.php`；
- 全部初始化脚本幂等，重复执行不会产生脏数据。

## 3.2 认证与会话

```
GET  /api/auth/captcha  → {uuid, code}（4 位大写字符，缓存 300 秒，一次性消费，大小写不敏感）
POST /api/auth/login    → {token, expiresIn: 7200}
GET  /api/auth/me       → {userId, username, nickname, deptId, deptName, roles[], permissions[]}
GET  /api/auth/routes   → {routes: 菜单树}
PUT  /api/auth/password → 修改本人密码（旧密码校验 + 新旧不能一致）
POST /api/auth/logout   → 吊销当前令牌 + 写登录日志
```

- JWT（HS256）claims：`jti`（随机 ID，每次登录独立）、`sub`（用户名）、`userId`、`iat`、`exp`；
- 双重校验：JWT 验签 **且** 令牌存储中存在 `auth:token:{jwt}` = 用户名，退出登录即删除，改密后旧令牌自然到期；
- 登录校验顺序：验证码 → 账号密码（BCrypt）→ 账号状态；失败均写登录日志（`登录成功 / 账号或密码错误 / 账号已停用`）；
- 前端 `api/session.ts`：记住登录存 localStorage，否则 sessionStorage；任一接口 401 统一清会话回登录页。

## 3.3 权限体系（菜单 / 按钮两级）

- 菜单表 `sys_menu` 三种类型：`dir`（目录）、`menu`（页面）、`btn`（按钮）；页面与按钮都带 `permission` 权限码，如 `system:user:add`；
- 后端每个接口在路由表上标注权限码（`RequirePermission` 中间件）：

```php
$group->post('/users', [SystemManagementController::class, 'createUser'])
    ->add(new OperLog('用户管理', '新增'))
    ->add(new RequirePermission('system:user:add'));
```

- 校验逻辑（`PermissionService::hasPermission`）：账号停用 → false；角色含 `super_admin` → true；否则权限码 ∈ 用户菜单权限集合；
- 前端同样以权限码控制按钮显示（`v-permission` 指令 / `PermissionButton` 组件），权限集合来自 `/api/auth/me`；
- 权限码速查：

| 模块 | 权限码 |
| --- | --- |
| 用户 | `system:user:list / add / edit / remove / resetPwd` |
| 角色 / 菜单 / 部门 / 岗位 / 字典 / 参数 | `system:role|menu|dept|post|dict|config` + `list / add / edit / remove` |
| 日志 | `monitor:operlog:list|remove`、`monitor:loginlog:list|remove` |
| 代码生成 | `tool:gen:list` |
| 主题中心 | `system:theme:list`（页面级，无数据接口） |

## 3.4 数据权限（Data Scope）

角色字段 `data_scope` 决定该角色用户可见的数据行：

| 值 | 含义 | SQL 效果 |
| --- | --- | --- |
| ALL | 全部 | 无附加条件 |
| DEPT_AND_CHILD | 本部门及下级 | `dept_id IN (本部门 + FIND_IN_SET 部门祖级链)` |
| DEPT | 本部门 | `dept_id = 本部门` |
| CUSTOM | 自定义 | `dept_id IN (sys_role_dept 自选部门)` |
| SELF | 仅本人 | `id = 本人` |

- 解析入口 `DataScopeService::resolve()`，多角色取**并集**；应用点：用户列表 / 用户导出 / 权限图谱的用户节点（`usersVisible`）；
- 新业务接入：在查询 SQL 的 WHERE 中拼入 `scopeClause()`（参考 `SystemManagementRepository::userWhere()`）；
- 权限图谱 `GET /api/system/permissions/graph` 一次返回角色、菜单、用户与关联，供溯源视图 / 星图 / 问答在前端组合；用户节点仅对有 `system:user:list` 的账号返回并遵守数据范围。

## 3.5 审计（操作日志 / 登录日志）

- **操作日志**：`OperLog` 路由中间件，标注模块与动作（如 `用户管理 / 新增`）；记录请求方法、URL、参数（`password / token / secret / authorization` 打码）、操作人、IP（X-Forwarded-For 优先）、归属地（本机 / 内网）、耗时、结果、错误信息；
- **登录日志**：登录成功 / 失败 / 退出、`last_login_time` 更新，全部在认证链路内完成；
- **监控读数**（`MonitorStatsService`）：概览（总量 / 失败率 / 平均与 P95 耗时 / 活跃人数）、按小时或按天趋势、当日按模块泳道（15 分钟内相邻操作合并为块，块内携带明细 ID 供跳转）、登录热力（星期 × 小时）、异常聚合（同 IP / 同账号失败达阈值，阈值可由参数 `sys.login.alertThreshold` 覆盖）；
- 全部列表支持关键词 + 分页 + CSV 导出（中文表头）与删除 / 清空（需 `remove` 权限）。

## 3.6 统一响应与错误语义

| 场景 | HTTP | body.code | message |
| --- | --- | --- | --- |
| 成功 | 200 | 200 | 操作成功 |
| 业务校验失败（BusinessException） | 400 | 400 或自定义 | 具体文案，如「登录账号已存在」 |
| 会话失效 / 未登录 | 401 | 401 | 未认证或登录已过期 |
| 无权限 | 403 | 403 | 没有访问权限 |
| 未匹配接口 | 404 | 404 | 资源不存在 |
| 方法不允许 | 405 | 405 | 不支持的请求方法: GET |
| 未处理异常 | 500 | 500 | 系统内部错误（同时写 `runtime/logs/`） |

> 注意：`BusinessException(401, '…')` 的 HTTP 状态仍为 400，body.code 为 401——前端对两者都做登出处理。

## 3.7 工作台

`GET /api/dashboard/summary?range=24h|7d|30d` 一次返回：

- `stats`：用户总数、在线用户（近 1 小时登录）、角色数量、24h 接口调用、菜单项、部门数，每项带环比（`delta` / `up` / `fresh`，上周期为 0 时标记为「新增」避免误导）；
- `trend` / `trendPrev`：登录脉搏曲线与上一周期对比；
- `dailyOps`：近 7 天操作量与失败量；`activities`：最近 8 条登录动态；`roleDist`：按数据范围的分布；`successRate`：区间接口成功率。

## 3.8 代码生成器

```
GET  /api/tool/generator/importable-tables   当前库可导入表（information_schema）
POST /api/tool/generator/import              导入表与字段元数据 → gen_table / gen_table_column
GET  /api/tool/generator/tables              配置列表（分页）
GET  /api/tool/generator/tables/{id}/columns 字段配置（增改/列表/查询/必填…）
PUT  /api/tool/generator/tables/{id}         保存说明与确认标记
GET  /api/tool/generator/tables/{id}/preview 预览 7 个文件
POST /api/tool/generator/tables/{id}/generate
GET  /api/tool/generator/tables/{id}/download 下载 ZIP（纯 PHP deflate，文件名取类名）
```

7 个产物：仓储 / 服务 / 控制器 / 路由注册片段（PHP 骨架，命名空间 `Linc\`）、前端 API / 页面（Vue 骨架）、菜单 SQL。输出是**开发骨架**：业务 CRUD 需按 Linc-Admin-Dev 版《05 扩展开发实战》规范实现后接入。

## 3.9 多主题（主题中心）

- 页面：菜单「主题中心」（`/theme`，组件 `theme/index`），图库式展示已安装主题，点击即换、按浏览器记忆；
- 出厂主题：**灵枢青**（默认，复刻 DevUI 设计语言）与 **珍珠玻璃**（经典玻璃拟态）；
- 如需开发自己的主题，请使用 Linc-Admin-Dev（源码开发版），其 `docs/05-扩展开发实战.md` 提供完整主题开发教程。
