# 灵枢中控 Linc-Admin-Dev（源码开发版）

> 统一管理后台 · 兼具设计美学与高效开发的 PHP 中后台模板
> **本版本为源码开发版**：包含前端源码（frontend/）与开发文档全集，面向二次开发；部署前需完成一次构建（Composer + npm，见 docs/12）。

灵枢中控是一套 PHP 中后台管理系统：安装向导三步完成部署，账号、权限、组织、字典与审计开箱即用；前端基于 Vue 3 自有组件库，内置多主题体系（出厂主题复刻 DevUI 设计语言），二次开发只需专注业务字段与流程。

- **后端**：PHP 8.0+ · Slim 4 · PDO MySQL · 零 Redis 依赖（可选启用）
- **前端**：Vue 3 · TypeScript · Vite · 自有「珍珠玻璃」组件体系 · 多主题
- **安装**：composer install + npm build → `public` 设为运行目录 → 访问域名 → 四步向导完成安装

> 只想直接使用、不做二开？请使用 **Linc-Admin-Ready（开箱即用版）**（见 `../Linc-Admin-Ready/README.md`）：依赖与前端已内置，上传即装。两版本功能与数据库完全一致。

## 系统亮点

| 亮点 | 说明 |
| --- | --- |
| 三步安装 | 环境检查 → 数据库连接（可自动建库）→ 管理员自定义账号密码，全程 Web 向导 |
| 多主题 | 令牌级主题包架构，主题中心即点即换；新增主题不改动任何业务页面 |
| 权限体系 | 菜单 / 按钮两级授权，前后端同一套权限码；数据权限五种粒度（全部 / 本部门及下级 / 本部门 / 自定义 / 仅本人） |
| 全程审计 | 操作日志与登录日志自动记录，趋势、泳道、热力与异常聚合一屏尽览 |
| 代码生成 | 导入数据表 → 配置字段 → 预览 7 个文件 → 下载 ZIP，业务模块开发骨架一键产出 |
| 统一底座 | 响应包络、分页、异常、追踪 ID、缓存、CSV / ZIP 等公共能力全部收敛于 `app/Core` |

## 功能总览

- **认证**：账号密码 + 字符验证码，JWT 会话（HS256，7200 秒），退出即吊销
- **管理**：用户（列表 / 看板）、角色（矩阵 / 溯源图谱）、菜单（星图）、部门（组织画布）、岗位、字典、参数、公告
- **外观**：主题中心（多主题切换）、浅色 / 深色 / 跟随系统、表格密度、导航轨折叠
- **监控**：操作日志、登录日志（概览 / 趋势 / 泳道 / 热力 / 异常聚合），CSV 导出
- **工具**：代码生成器、健康检查（`GET /api/health`）

## 快速开始

环境要求：**PHP ≥ 8.0**（扩展 `pdo_mysql`）、**Composer**、**Node.js 22+**、**MySQL ≥ 5.7**；Nginx / Apache / 宝塔任一，本地可用 PHP 内置服务器。本版本不内置依赖与构建产物，首次部署需要一次构建：

```bash
composer install --no-interaction --optimize-autoloader   # PHP 依赖 → vendor/
cd frontend && npm ci && npm run build && cd ..           # 前端构建 → frontend/dist/
cp -r frontend/dist/* public/                             # 前端产物部署到 public/
```

```bash
# 本地体验（构建完成后）
php -S 127.0.0.1:8090 -t public public/index.php
```

1. 把整个项目（**含 vendor/ 与已构建的 public/**）放到站点目录，将**运行目录（网站根目录）设置为 `public/`**（宝塔：网站 → 设置 → 网站目录）。
2. 浏览器访问域名，自动进入安装向导，填入数据库信息完成安装。
3. 使用安装时设置的管理员账号登录（不填则默认 `admin / admin123`）。

完整部署教程（含服务器直接构建的路径）见 [docs/12-安装教程-从零开始.md](docs/12-安装教程-从零开始.md)；服务器配置细节见 [docs/06-配置与部署.md](docs/06-配置与部署.md)。

## 目录结构

```
Linc-Admin/
├── public/            # 唯一 Web 运行目录（前端构建产物 + index.php 前置控制器 + 安装向导）
├── app/
│   ├── Application/   # Slim 装配与路由表（路径、权限码、操作日志标注）
│   ├── Core/          # 响应包络、JWT、缓存、验证码、CSV / ZIP、数据库等公共基类
│   ├── Middleware/    # 追踪 ID、认证、权限、操作日志、统一异常
│   ├── Controller/    # 业务控制器 + 安装器控制器
│   ├── Repository/    # 数据访问层（SQL 集中于此）
│   └── Service/       # 业务逻辑层（校验与规则）
├── config/            # config.php（安装生成）；config.sample.php 为手工模板
├── database/          # V1 建表 / V2 种子数据 / V3 主题菜单（幂等，按版本号顺序执行）
├── runtime/           # 缓存、日志、install.lock（Web 不可达）
├── frontend/          # Vue 3 前端源码（二次开发入口）
├── tests/             # api_contract.php 契约回归脚本（37 项断言）
└── docs/              # 开发者文档（概述 / 架构 / 规范 / 实战 / 部署 / FAQ…）
```

## 二次开发

- **开发文档**：从 [docs/01-项目概述.md](docs/01-项目概述.md) 开始，按「概述 → 架构 → 功能模块 → 规范 → 实战」顺序阅读；扩展新模块、开发新主题的完整教程在 [docs/05-扩展开发实战.md](docs/05-扩展开发实战.md)。
- **前端开发**：`cd frontend && npm ci && npm run dev`（Vite 代理 `/api` 到后端）；改完执行 `npm run build` 并将 `dist/` 内容拷入 `public/`。
- **回归验证**：安装完成后执行 `php tests/api_contract.php http://你的域名`，覆盖响应包络、状态码文案、分页、校验文案、导出、生成器等 37 项契约断言。
