# 灵枢中控 Linc-Admin-Ready（开箱即用版）

> 统一管理后台 · 兼具设计美学与高效开发的 PHP 中后台模板
> **本版本为开箱即用版**：内置全部 PHP 依赖与已构建的前端页面，上传服务器即可安装，**无需 Composer、无需 Node.js**。

灵枢中控是一套开箱即用的 PHP 中后台管理系统：安装向导三步完成部署，账号、权限、组织、字典与审计开箱即用；内置多主题体系（出厂主题复刻 DevUI 设计语言），浅色 / 深色随心切换。

## 本版本与源码开发版的区别

| | **本版本（Ready，开箱即用）** | **Linc-Admin-Dev（源码开发版）** |
| --- | --- | --- |
| 面向人群 | 只想直接使用后台的用户 | 需要二次开发的开发者 |
| PHP 依赖（vendor/） | ✅ 已内置 | 🔧 需自行 `composer install` |
| 前端页面 | ✅ 已构建，直接可用 | 🔧 需自行 `npm ci && npm run build` |
| 前端源码（frontend/） | ❌ 不包含 | ✅ 包含 |
| 开发文档（规范 / 实战 / 基类附录） | ❌ 不包含 | ✅ 包含 |
| 部署步骤 | 上传 → 建站 → 安装向导 | 构建 → 上传 → 建站 → 安装向导 |

> 想做二次开发（新增模块、自定义主题、改页面）？请下载 **Linc-Admin-Dev** 版，其 `docs/05-扩展开发实战.md` 含完整教程。两个版本功能完全一致，数据库结构通用。

## 功能总览

- **认证**：账号密码 + 字符验证码，JWT 会话（HS256，7200 秒），退出即吊销
- **管理**：用户（列表 / 看板）、角色（矩阵 / 溯源图谱）、菜单（星图）、部门（组织画布）、岗位、字典、参数
- **外观**：主题中心（多主题切换）、浅色 / 深色 / 跟随系统、表格密度、导航轨折叠
- **监控**：操作日志、登录日志（趋势 / 泳道 / 热力 / 异常聚合），CSV 导出
- **工具**：代码生成器（导出开发骨架，供 Dev 版接入）、健康检查

## 快速开始（三步）

环境要求：**PHP ≥ 8.0**（扩展 `pdo_mysql`）、**MySQL ≥ 5.7**，其他什么都不用装。

1. **上传**：把整个项目放到站点目录，将运行目录设置为 `public/`（宝塔：网站 → 设置 → 网站目录）；
2. **安装**：浏览器访问域名，自动进入安装向导，填数据库信息完成安装；
3. **登录**：使用安装时设置的账号登录（默认 `admin / admin123`）。

零基础、第一次买服务器？跟着图文教程一步步走：[docs/12-安装教程-从零开始.md](docs/12-安装教程-从零开始.md)。

## 目录结构

```
Linc-Admin-Ready/
├── public/            # 唯一 Web 运行目录（已构建的前端页面 + 前置控制器 + 安装向导）
├── app/               # PHP 后端（控制器 / 服务 / 仓储 / 公共基类）
├── vendor/            # PHP 依赖（已内置，无需 Composer）
├── config/            # config.php 由安装向导生成；config.sample.php 为手工模板
├── database/          # 初始化脚本（V1 建表 / V2 种子数据 / V3 主题菜单）
├── runtime/           # 缓存、日志、install.lock（Web 不可达）
└── docs/              # 使用与部署文档
```
