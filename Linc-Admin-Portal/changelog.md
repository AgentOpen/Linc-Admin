# 更新日志（Linc-Admin）


## [1.2.0] - 2026-11-07

### 新增
- **门户一体能力（前后台联动）**：新增「公告管理」模块（biz_announce，后台 CRUD + 权限码 biz:announce:*）；主题中心切换皮肤写入服务端（sys.index.skin），门户前台实时跟随；public/index.php 支持 portal.enabled 开关（true：/ 为门户前台、/admin 为管理后台）。
- **主题皮肤服务端持久化**：PUT/GET /api/theme/skin（权限码 system:theme:edit）。
- 安装向导 v2：深空粒子背景、玻璃分栏（品牌轨 + 垂直步骤器）、逐项入场动效，尊重减少动效偏好；接口不可达时给出伪静态修复指引。
- 内联 SVG favicon（前端 + 安装向导），消除 favicon 404。

### 变更
- 初始管理员昵称改为「管理员」（种子数据与安装向导同步）。
- 主题中心重构：移除冗余介绍区块，新增当前主题舞台横幅（渐变流动 + 徽章脉冲）与大间距画廊（预览线条生长 / 柱状起伏微动效）。
- 前端构建支持 VITE_ADMIN_BASE（门户版管理后台置于 /admin）。

### 修复
- 安装向导接口 404 时的引导文案（伪静态未配置场景，来自用户实测反馈）。

## [1.1.0] - 2026-11-06

### 新增
- **多主题体系**：主题 = CSS 设计令牌覆盖包（`data-skin`），与明暗（`data-theme`）、表格密度（`data-density`）三维正交组合；主题中心页面（`/theme`）图库式切换、按浏览器记忆。
- **出厂主题「灵枢青」**（默认）：复刻 DevUI 设计语言——靛蓝主色、冷灰画布、纯白面板、小圆角、轻阴影、扁平材质，含完整暗色档；经典主题「珍珠玻璃」保留为可切换项。
- **主题开发路径**：新增主题约 30 分钟（令牌覆盖 + 注册表登记），详见 `docs/05-扩展开发实战.md`。
- **安装器版本化脚本**：自动按版本号顺序执行 `database/V*__*.sql`，后续数据库变更只需新增脚本。

### 变更
- 代码生成器产物全面 PHP 化：生成仓储 / 服务 / 控制器 / 路由注册片段（`Linc\` 命名空间）+ Vue 页面 + 菜单 SQL；`gen_table_column` 字段更名 `java_field/java_type/jdbc_type → field_name/field_type/data_type`。
- 文档体系扩展至 13 章：新增《12 安装教程（从零开始）》《13 使用手册》，设计规范并入 `docs/设计规范.md`。

### 修复
- 主题切换后图表 / 图谱配色随主题联动的令牌覆盖（`--graph-*` RGB 三元组）。

## [1.0.0] - 2026-11-06

### 新增
- 首个开源版本：PHP 8.0+ / Slim 4 / PDO MySQL 后端 + Vue 3 / TypeScript / Vite 前端。
- **认证**：账号密码 + 字符验证码（300 秒一次性），JWT HS256 会话（7200 秒），退出即吊销；BCrypt 密码。
- **权限**：菜单 / 按钮两级授权，前后端同一套权限码，`super_admin` 直通；数据权限五种粒度（全部 / 本部门及下级 / 本部门 / 自定义 / 仅本人）。
- **管理页面**：工作台、用户（列表 / 看板）、角色（矩阵 / 溯源图谱）、菜单（星图）、部门（组织画布）、岗位、字典、参数、操作日志、登录日志（趋势 / 泳道 / 热力 / 异常聚合）、代码生成。
- **审计**：写接口操作日志自动记录（参数脱敏、耗时、IP 归属），登录事件独立成表，CSV 导出。
- **代码生成**：导入数据表 → 字段配置 → 预览 7 个文件 → 下载 ZIP。
- **Web 安装向导**：环境检查 → 数据库连接（可自动建库）→ 管理员自定义账号密码 → 建库导表落锁（`runtime/install.lock`）。
- **统一底座**：响应包络 `{code, message, data, traceId}`、分页模型、统一异常、追踪 ID、文件缓存（可选 Redis）、CSV / ZIP 工具类。
- **回归脚本**：`tests/api_contract.php` 37 项契约断言。

### 安全
- 操作日志自动脱敏 `password / token / secret / authorization` 字段；
- 安装完成后 `/api/install/*` 一律返回 403；
- 敏感目录（app / config / database / runtime 等）不在 Web 运行目录内，Apache / Nginx 配置示例附带拦截规则。
