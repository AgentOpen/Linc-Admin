# 灵枢中控 Linc-Admin-Portal（门户一体版）

> 统一管理后台 · 前后台一体：**域名根 `/` 是门户前台（服务端渲染），`/admin` 是管理后台**
> 内置 PHP 依赖与已构建页面，上传服务器即可安装，**无需 Composer、无需 Node.js**。

这是灵枢中控的「前后台不分离」发行版（类似传统 CMS 的使用方式）：

- **`/` 门户前台**：PHP 服务端渲染的展示站点——品牌 Hero、公告动态（来自后台「公告管理」）、系统能力介绍；
- **`/admin` 管理后台**：完整的灵枢中控管理 SPA（用户 / 角色 / 主题 / 公告 / 日志 / 代码生成）；
- **主题联动**：后台「主题中心」切换皮肤（灵枢青 / 珍珠玻璃）时，选择会写入服务端，**门户前台外观实时跟随**。

## 快速开始（三步）

环境要求：**PHP ≥ 8.0**（`pdo_mysql`）、**MySQL ≥ 5.7**，其它什么都不用装。

1. **上传**：项目放到站点目录，运行目录设为 `public/`；
2. **安装**：访问域名进入安装向导（伪静态记得配：站点设置 → 伪静态 → `laravel5`）；
3. **使用**：安装完成后访问域名即是门户前台，`/admin` 进管理后台。

零基础图文教程：[docs/12-安装教程-从零开始.md](docs/12-安装教程-从零开始.md)。

## 上手三件事

1. `/admin` 登录后先改密码、清理演示账号；
2. 左侧「公告管理」发布几条公告 → 打开域名首页即可看到「公告动态」更新；
3. 「主题中心」切换皮肤 → 门户前台与后台同时换装。
