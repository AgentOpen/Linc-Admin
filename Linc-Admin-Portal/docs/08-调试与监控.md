# 08 · 调试与监控

## 8.1 追踪 ID（traceId）

- 每个请求生成 32 位追踪 ID：优先取请求头 `X-Trace-Id`，否则自动生成；
- 响应头 `X-Trace-Id` 与响应包络 `traceId` 字段同值；前端 `ApiError` 也会携带；
- **排障流程**：前端报错弹层 → 取 traceId → 在服务器日志中检索同 ID，即可定位该次请求的异常栈。

## 8.2 日志体系

| 日志 | 位置 | 内容 |
| --- | --- | --- |
| 应用错误日志 | `runtime/logs/error-YYYYMMDD.log` | 未处理异常（HTTP 500）完整栈 + 请求方法与 URI |
| 操作日志（业务） | `sys_oper_log` 表 | 后台「操作日志」页查询；写接口的模块 / 动作 / 参数（脱敏）/ 耗时 / 结果 |
| 登录日志（业务） | `sys_login_log` 表 | 后台「登录日志」页查询；成功 / 失败 / 退出 |
| PHP 自身日志 | PHP-FPM / error_log 配置 | 启动错误、Fatal Error |

> 业务审计日志（两张表）可按需清理（单条删除或清空，需 `monitor:*:remove` 权限）；清空前建议 CSV 导出归档。

## 8.3 健康检查与探活

```bash
curl -s http://127.0.0.1:8090/api/health
# {"code":200,"message":"操作成功","data":{"status":"UP","time":"2026-11-06T01:20:00+08:00"},"traceId":...}
```

- 免认证、无数据库写入，适合负载均衡 / 拨测系统探活；
- 需要带数据库探活时自行扩展（注意别把凭据打进响应）。

## 8.4 契约回归（最强排障工具）

任何改动后先跑：

```bash
php tests/api_contract.php http://127.0.0.1:8090
# 结果：37 通过，0 失败
```

37 项断言覆盖：响应包络、401/403/404/405 文案、分页上限、业务校验文案（登录 / 用户 / 状态 / 内置保护）、CSV 表头、字典与引用选项、工作台与监控统计结构、代码生成（导入 / 预览 / ZIP）、安装守卫、登出吊销。**失败项即回归点**，比读代码更快定位破坏面。

## 8.5 浏览器侧调试

- Vue Devtools：查看 Pinia 式响应式状态（会话、权限、外观）；组件树里 `auth.ts` 的会话状态一目了然；
- Network：每个请求的 `X-Trace-Id` 响应头可与后端日志对齐；
- 外观排障：控制台执行
  ```js
  JSON.parse(localStorage.getItem('linc.appearance'))   // 皮肤 / 明暗 / 密度
  document.documentElement.dataset                       // data-skin / data-theme / data-density
  ```
- 401 循环排查：`linc.token` 是否过期（`linc.expiresAt`）→ 服务器 `runtime/cache/` 是否被清（多机部署共享问题见《09》）。

## 8.6 常见排障路径（症状 → 现场表）

| 症状 | 第一现场 | 排查重点 |
| --- | --- | --- |
| 登录成功但无菜单 | `/api/auth/routes` | 角色是否启用、是否分配菜单、角色管理里重新授权 |
| 菜单可见但接口 403 | `runtime/logs` + 操作日志 | 路由表权限码与菜单权限码是否一致、账号状态 |
| 切换账号后旧菜单仍在 | 前端会话 | `sessionVersion` 机制自动清理；手动清 localStorage 复测 |
| 接口全部 401 | `runtime/cache/` | 令牌是否被清（重启清缓存属正常，重新登录）；多机共享问题 |
| 页面空白 / 样式错乱 | 浏览器 Network | index.html 是否缓存了旧资源 hash；强刷（Ctrl+F5） |
| 时间差 8 小时 | `config/config.php` | `database.timezone` 与数据库 `time_zone` |
| 代码生成 ZIP 打不开 | `zlib` 扩展 | 环境检查步骤会提示；安装 php-zlib |
| 500 且无业务文案 | `runtime/logs/error-*.log` | 按 traceId / 时间定位完整栈 |

## 8.7 监控接入建议

- **指标**：`/api/health` 存活 + 登录接口成功率（可从 `sys_login_log` 聚合）+ 接口耗时 P95（`sys_oper_log.cost`）；
- **告警阈值**：登录失败聚合已内置（同 IP / 同账号 ≥ 阈值，`sys.login.alertThreshold` 可配），可直接在登录日志「热力」页查看；
- **日志采集**：`runtime/logs/*.log` 与两张审计表可对接 Filebeat /自定义脚本；表数据量大时按月归档。
