# 设计规范（珍珠玻璃体系 · 多主题）

> 本规范与 `frontend/src/styles` 七层样式、公共组件及动效入口一致，是所有主题与页面的共同基线。视觉规格见 `styles/tokens.css` 注释。

## 1. 多主题模型

外观由三个正交维度组成，全部以 `<html>` 属性表达、按浏览器记忆：

| 属性 | 取值 | 说明 |
| --- | --- | --- |
| `data-skin` | `linc`（灵枢青，出厂默认）/ `pearl`（珍珠玻璃）/ 自定义 | 主题包 = `styles/themes/<key>.css` 的令牌覆盖 + `themes/index.ts` 注册 |
| `data-theme` | `light` / `dark` / `auto` | 明暗；`auto` 跟随系统 |
| `data-density` | `comfy` / `regular` / `compact` | 表格行高与单元格内距 |

主题包只覆盖差异令牌，未覆盖的回退 `tokens.css` 基线；**页面与组件只引用令牌，禁止手写颜色 / 圆角 / 阴影字面量**——这是多主题成立的前提。

## 2. 视觉语言

以柔和的灰白背景、清晰阅读面、克制的玻璃浮层和细边线组织信息；蓝色用于选择与主操作，青柠（灵枢青主题下为绿色系）用于正常状态，红色用于危险操作。深色使用同一语义和布局，颜色与材质由主题令牌切换。

页面结构遵循：页面标题与主操作 → 查询区 → 表格面板与工具栏 → 分页；业务侧栏放在统一分栏结构中。页面只补业务差异，不另写一套按钮、表格、弹窗或筛选布局。

在此之上叠加「仪器化」语汇：显示级等宽读数配上标单位、深色规格铭牌、环比胶囊、刻度尺与斜线填充。它们表达「读数、区间、当前位置」，不作装饰；每页只有一个视觉主角，其余缩为小块。文案一律使用业务中文；等宽字体只留给数字、编码、权限标识与时间。

## 3. 核心令牌

| 令牌 | 中文含义 |
| --- | --- |
| `--ink` / `--ink-muted` / `--ink-soft` / `--ink-faint` | 正文、次级正文、标签、元信息四档字色 |
| `--blue` / `--blue-hover` / `--blue-soft` / `--focus` | 主操作色及悬停、浅底、焦点环 |
| `--leaf-text` / `--lime(-soft)` / `--red(-text/-soft)` | 状态色：正常 / 能力 / 警示 |
| `--r-xs` … `--r-xl` | 圆角五档（胶囊 999px） |
| `--e1` / `--e2` / `--e3` / `--edge` | 阅读面 / 高亮块 / 浮层阴影与玻璃上缘 |
| `--stage` / `--canvas` / `--rail-bg` / `--pill-bg` / `--surface` / `--float-bg` / `--input-bg` | 场景面与四种材质配方 |
| `--cat-1…5(-bg/-ink)`、`--graph-1…5` | 分类色与图谱 Canvas 的 RGB 三元组（换主题必须同步覆盖后者） |
| `--row-h` / `--cell-px` / `--rail-w` / `--topbar-h` / `--control-h` | 密度与布局尺寸 |

字体使用系统字体栈（SF Pro、苹方、Noto Sans SC、微软雅黑），无需联网下载；数值用等宽数字。

## 4. 七层样式

| 文件（`frontend/src/styles/`） | 职责 |
| --- | --- |
| `tokens.css` | 颜色、字色、尺寸、圆角、阴影、明暗与密度（唯一令牌来源） |
| `base.css` | 基础元素、可见焦点、全局布局基线 |
| `materials.css` | 阅读面、导航轨、玻璃块、浮层与槽 |
| `components.css` | 按钮、输入、下拉、表格、标签和浮层 |
| `instruments.css` | 眉标、读数、铭牌、刻度尺、图表、泳道、画布、看板、矩阵、底部浮条 |
| `layout.css` | 外壳、导航、顶栏、页面与分栏 |
| `pages.css` | 登录、工作台、主题中心、生成预览等业务差异 |
| `themes/<key>.css` | 主题覆盖包（只写差异令牌） |

按上表顺序在 `main.ts` 引入；通用变化写入所属层，避免用页面选择器覆盖整个控件库。

## 5. 材质

| 类名 | 用途 |
| --- | --- |
| `m-rail` | 接近实色的导航轨 |
| `m-pill` | 高亮玻璃块（选中导航、次级按钮、分段滑块） |
| `m-float` | 高层级浮层（下拉选项、命令面板、提示） |
| `m-surface` | 接近实色的阅读面（表格、卡片、弹窗） |
| `m-groove` | 凹槽（分段控件底座、导入列表） |

玻璃效果只用于材质层级，不降低表格与正文的可读性；选择、危险、停用等状态必须同时有文字或图标，不能只靠颜色表达。

## 6. 版式与视图

| 版式 | 页面 |
| --- | --- |
| 主次布局 | 工作台（主卡 + 侧块 + 柱状 / 刻度环 / 占比条 + 当日泳道 + 最近登录） |
| 横带分层 | 操作日志、登录日志（概览 → 趋势或泳道 / 热力 → 异常聚合 → 明细） |
| 画布 + 浮动面板 | 部门管理（组织树平移缩放） |
| 看板分列 | 用户管理（仅「按状态」可拖拽，卡片菜单支持键盘移动） |
| 矩阵 | 角色管理（菜单 × 角色，悬停十字高亮，改动累计浮条一次提交） |
| 溯源图谱 / 导航星系 / 岗位阶梯 | 角色菜单岗位的图谱舞台（三层下钻） |
| 设置面板 | 参数管理（按前缀分组行内编辑） |
| 样本册 | 字典管理 |
| 流水线 | 代码生成抽屉 |
| 主题图库 | 主题中心（迷你布局预览卡片） |

视图切换通过 `ListPage` 的 `altView` 与 `#alt` 插槽，偏好由 `composables/view.ts` 按页面记忆；820px 以下首次进入默认表格。

图谱舞台（`RelationGraph variant="stage"`）不使用叠加发光、粒子或强制深色底；Canvas 绘制件集中在 `composables/neural.ts`，DOM 只保留可点标签；性能红线：DPR ≤ 2、离屏暂停、每帧 try/catch、每条线脉冲 ≤ 2。

## 7. 组件约定

- 列表 `ListPage` + `useListPage`（树列表 `useTreeListPage`）；表单 `FormDialog` / `Field` / `TextInput` / `Select` / `Switch` / `Checkbox`；权限操作 `PermissionButton`——前端隐藏不能替代后端校验；
- 字典与引用：`DictSelect`、`DictTag`、`DeptTree`、`DeptSelect`、`UserSelect`；
- 读数 `Metric` / `Odometer`，分区 `SectionLabel`，铭牌 `SpecPlate`，环比 `DeltaPill`（上周期为 0 显示「新增」而非 +100%）；
- 表格操作列（`col-actions`）吸附右侧；批量操作用底部深色玻璃浮条 `.float-bar`；
- 多层浮层共用 `focus.ts`：后开置顶、Escape 只作用最上层、关闭恢复触发控件焦点；
- 页面文案说明业务含义，不展示组件名或实现函数名。

## 8. 动效与可访问性

统一入口 `composables/motion.ts`（`EASE` / `DUR` / `createFrameLoop` / `spring` / `revealCascade` / `typeOut`），不在页面复制 GSAP 配方。四种能量语态：放（按压涟漪、弹窗展开）、导（折线描绘、刻度点亮）、结（读数落定、看板落位）、停摆（取消飞回、浮条下沉）。

- 常驻动画只动 `transform` / `opacity`；减少动效（`skipMotion()`）与后台标签页直接进入可见终态；
- 下拉支持方向键 / Enter / Escape / Tab；表单保留关联标签、校验提示与可见焦点；图标按钮提供中文无障碍名称。

## 9. 新页面验收

核对查询、重置、分页、导出、状态与行操作；新版式另核对视图切换记忆与键盘替代路径。验证成功、校验失败与权限不足分支。选择代表性页面检查**两套主题 × 明暗 × 三档密度**、手机宽度、键盘与减少动效；公共组件改动同时检查其直接使用页面。构建和截图用于辅助检查，不能替代真实接口与用户操作的流程验收。
