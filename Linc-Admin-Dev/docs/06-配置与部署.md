# 06 · 配置与部署

## 6.1 环境要求

| 项 | 要求 |
| --- | --- |
| PHP | ≥ 8.0（推荐 8.1+）；扩展：`pdo_mysql`（必选）、`zlib`（默认内置）；常用安全配置 `cgi.fix_pathinfo=0` |
| MySQL | ≥ 5.7（兼容 8.0、MariaDB 10.4+）；字符集 utf8mb4 |
| Web 服务器 | Nginx / Apache / 宝塔；本地开发可用 PHP 内置服务器 |
| Node.js | 仅前端二次开发需要（22+）；纯部署不需要 |

## 6.2 配置项（config/config.php）

由安装向导自动生成；手工部署可复制 `config/config.sample.php` 修改：

```php
return [
    'database' => [
        'host' => 'localhost',       // MySQL 地址
        'port' => 3306,              // 端口
        'name' => 'linc_admin',      // 数据库名（字母数字下划线）
        'username' => 'root',        // 账号
        'password' => '',            // 密码
        'timezone' => '+08:00',      // 会话时区（影响 NOW() 与时间展示口径）
    ],
    'jwt' => [
        'secret' => '至少 32 字节的随机密钥', // 安装器自动生成 64 位十六进制
        'expires_seconds' => 7200,           // 登录有效期（秒）
    ],
    'cache' => [
        'driver' => 'file',          // file（默认，零依赖）或 redis
        'redis' => ['host' => 'localhost', 'port' => 6379, 'password' => ''],
    ],
];
```

- 环境变量覆盖：`DB_HOST / DB_PORT / DB_NAME / DB_USERNAME / DB_PASSWORD / DB_TIMEZONE / JWT_SECRET / JWT_EXPIRES_SECONDS / CACHE_DRIVER / REDIS_HOST / REDIS_PORT / REDIS_PASSWORD`，优先于配置文件，便于容器化；
- **更换 JWT 密钥会使全部已登录会话失效**；多机部署时各机配置必须一致（或共享缓存）。

## 6.3 宝塔面板（推荐）

1. 上传项目到站点目录（内含 `public/`）；
2. 网站 → 设置 → **网站目录**：运行目录选 `public`，保存；
3. 网站 → 设置 → **伪静态**：选 `laravel5` 模板，或粘贴：

   ```nginx
   location / {
       index index.html index.php;
       try_files $uri $uri/ /index.php?$query_string;
   }
   ```

4. 软件商店 → PHP → 安装扩展 → `pdo_mysql`；
5. 访问域名进入安装向导。

## 6.4 Nginx（public 为运行目录，推荐）

```nginx
server {
    listen 80;
    server_name admin.example.com;
    root /var/www/Linc-Admin/public;
    index index.html index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;        # 或 unix:/run/php/php8.2-fpm.sock
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

## 6.5 Nginx（无法修改运行目录）

`root` 指向项目根，显式拒绝敏感目录，PHP 脚本固定转发到 `public/index.php`：

```nginx
root /var/www/Linc-Admin;

location ~ ^/(app|config|database|runtime|tests|docs|frontend)/ { deny all; }
location ~ /composer\.(json|lock)$ { deny all; }

location / {
    try_files $uri $uri/ /index.php?$query_string;
}
location ~ \.php$ {
    fastcgi_pass 127.0.0.1:9000;
    fastcgi_param SCRIPT_FILENAME /var/www/Linc-Admin/public/index.php;
    include fastcgi_params;
}
```

项目根已内置 `index.php` 垫片与 `.htaccess`（Apache 用，含敏感目录拦截）。

## 6.6 Apache

- **public 为文档根**：启用 `mod_rewrite` + `AllowOverride All`，`public/.htaccess` 已内置（静态优先，其余转 index.php）；
- **项目根为文档根**：根目录 `.htaccess` 已内置转发与敏感目录（app / config / database / runtime / tests / docs / frontend）拦截。

## 6.7 本地开发

```bash
# 后端 + 已构建前端
php -S 127.0.0.1:8090 -t public public/index.php

# 前端热更新（另开终端；Vite 代理 /api → http://localhost:8090）
cd frontend && npm ci && npm run dev

# 前端构建产物部署
cd frontend && npm run build && cp -r dist/* ../public/
```

## 6.8 目录权限

- `runtime/`、`config/` 需要 PHP 进程用户写权限（安装向导环境检查会提示）；
- 生产建议：`chmod -R 750 app config database tests docs frontend`；`runtime` 归属 PHP 进程用户；`public/` 内不要存放任何私密文件。

## 6.9 时区

- 安装向导「会话时区」默认 `+08:00`，写入 `database.timezone`；连接建立时执行 `SET time_zone`，保证数据库 `NOW()` 与业务口径一致；
- PHP 时区由该配置自动换算（`Etc/GMT±N`），无需另行设置；
- 修改时区后重新登录即可，历史记录按原样展示。

## 6.10 缓存与 Redis

### Redis 安全红线（必读）

Redis 是挖矿木马入侵 Linux 服务器最常被利用的入口（未授权访问 → 写文件执行）。启用 Redis 缓存前必须完成三件事：

1. **只允许本机连接**：redis.conf 中 `bind 127.0.0.1`；
2. **必须设置强密码**：`requirepass`（32 位以上随机串），并在 config/config.php 的 cache.redis.password 中同步；
3. **安全组关闭 6379 对公网**：任何情况下不要放行 6379 到 0.0.0.0/0。

验证：`redis-cli -h 127.0.0.1 ping` 需要密码（NOAUTH/ERR 而非 PONG）；云安全组无 6379 规则。被入侵的典型痕迹：以 redis 用户运行的陌生进程、/data 等数据目录出现可执行文件——立即杀进程排查持久化（cron、/etc/ld.so.preload、authorized_keys）并考虑重装系统。

- 默认 `file`：token 与验证码存 `runtime/cache/`，flock 保证原子性，单机部署零依赖；
- 切换 `redis`：修改配置后重启 PHP 进程即可；使用 Predis（纯 PHP），phpredis 扩展非必需；
- 多机部署：必须共享缓存（Redis 或共享存储挂载 `runtime/cache`），否则 token 只在单机有效。
