# 11 · 附录：核心基类与服务

> 后端命名空间 `Linc\`（`app/`），前端别名 `@/`（`frontend/src/`）。本附录是速查手册，细节见对应源码注释。

## 11.1 后端 Core（公共基类）

| 类 | 职责 | 关键 API |
| --- | --- | --- |
| `Core\R` | 统一响应包络 | `R::success($data)` / `R::error($code, $message)`；`{code, message, data, traceId}` |
| `Core\PageQuery` | 分页请求 | `PageQuery::fromQuery($_GET)`；`normalizedPageNum()`(默认1)、`normalizedPageSize()`(默认10,上限100) |
| `Core\PageResult` | 分页响应 | `PageResult::of($rows, $total, $pageNum, $pageSize)` → `{rows,total,pageNum,pageSize}` |
| `Core\BusinessException` | 业务异常 | `throw new BusinessException('文案', 400)`；HTTP 恒 400、body.code 可自定义 |
| `Core\Database` | PDO 网关 | `all / first / scalar / execute / insert`(返回自增ID)、`beginTransaction / commit / rollBack`、`pdoWithoutDatabase()`(安装器) |
| `Core\Cache` | 键值缓存 | `set($key, $val, $ttl)` / `get` / `delete`；file(flock) 与 redis 双驱动，语义一致 |
| `Core\TokenStore` | 令牌存储 | 键 `auth:token:{jwt}` = username，TTL=登录有效期；`store / usernameOf / revoke` |
| `Core\JwtCodec` | JWT 编解码 | HS256；claims `jti/sub/userId/iat/exp`；`encode($secret,$userId,$username,$ttl)` / `decode()`(无效返回 null) |
| `Core\Captcha` | 验证码 | 4 位大写字符（去易混淆集），300 秒一次性；`generate() → {uuid, code}` / `verify()` |
| `Core\Csv` | CSV 生成 | `Csv::build($headers, $rows)`；中文表头、双引号转义、无 BOM |
| `Core\ZipBuilder` | ZIP 打包 | 纯 PHP deflate（gzdeflate），`add($name, $content)` + `build()` |
| `Core\SqlScript` | SQL 拆分 | 按语句拆分整份脚本（支持注释与引号保护），供安装器逐条执行 |
| `Core\TraceId` | 追踪 ID | 32 位无横线 UUID；`resolve()` / `current()`；响应头 `X-Trace-Id` |
| `Core\AuthContext` | 会话上下文 | `username() / operator()`(兜底 system) / `currentUserRow()`(停用抛 401) / `token()` |
| `Core\DataScopeCriteria` | 数据范围条件 | `all() / selfOnly($uid) / limited($uid, $deptIds)`；供仓储拼 WHERE |
| `Core\Config` | 配置装载 | `get('a.b')`、`database()`、`jwtSecret()`、`cacheDriver()`；支持环境变量覆盖 |
| `Core\StringUtil` | 命名工具 | `upperCamel / lowerCamel / decapitalize`（生成器用） |

全局函数（`app/Core/helpers.php`）：`required()`(必填校验)、`trim_to_null()`、`default_string()`、`default_int()`、`bool_as_int()`、`number_as_long()`、`json_body()`(格式错误→「请求体格式错误」)、`client_ip()`(X-Forwarded-For 优先)、`location_of_ip()`(本机/内网)、`php_timezone_for_offset()`。

## 11.2 后端 Middleware

| 类 | 对应经典实现 | 行为 |
| --- | --- | --- |
| `Middleware\ApiErrorHandler` | GlobalExceptionHandler | BusinessException→400；404/405/500 文案统一；500 落文件日志 |
| `Middleware\TraceIdMiddleware` | TraceIdFilter | 最先生成/透传 traceId，响应头回写 |
| `Middleware\AuthMiddleware` | SecurityConfig + JwtFilter | Bearer 解析 + 令牌存储校验；公开路径白名单；未认证 401 |
| `Middleware\RequirePermission` | RequiresPermission + PermissionAspect | 路由级权限码校验，失败 403 |
| `Middleware\OperLog` | @OperLog + OperationLogAspect | 路由级审计：参数脱敏、耗时、IP、结果 |

## 11.3 后端 Service（业务规则归属）

| 服务 | 职责与要点 |
| --- | --- |
| `AuthService` | 登录校验顺序、登录日志、菜单树（`buildRoutes` 按 parent_id,sort,id 组树）、改密码校验 |
| `PermissionService` | 权限判定（超管直通）、`isSuperAdmin()` |
| `DataScopeService` | 五种数据范围解析（多角色并集），`current()` 即当前会话范围 |
| `SystemManagementService` | 用户/角色/菜单/部门/岗位/字典/参数 + 日志查询导出的全部业务规则；COALESCE 部分更新、树构建、布尔行转换、CSV 表头 |
| `DashboardService` | 工作台聚合：stats 六项读数与环比、登录脉搏、近 7 天操作、动态、分布 |
| `MonitorStatsService` | 监控统计：概览/趋势（小时/天）、当日泳道（15 分钟合并块 + BLOCK_ID_LIMIT=50）、登录热力与异常聚合（阈值默认 5，`sys.login.alertThreshold` 可覆盖） |
| `GeneratorService` | 代码生成：information_schema 导入、命名推导（upperCamel / module / businessName）、7 文件模板（`com.linc.<module>`）、ZIP |
| `InstallerController` | 安装器：环境检查、连接测试、按版本执行 `database/V*.sql`、写配置与锁 |

## 11.4 后端 Controller 与路由

- 控制器只做「参数 → 服务 → 包络」：`AuthController::ok($response, $data)`、`::csv()`、`::pageQuery()`、`::pathId()`(参数类型校验)、`::pathString()`；
- **路由表 `app/Application/AppFactory.php` 是权限与审计的总账**：每个 `/api` 路由的权限码（`RequirePermission`）与写操作标注（`OperLog`）都在这里登记；公开路径白名单在 `AuthMiddleware::PUBLIC_PATHS`；
- 接口清单（方法 + 路径 + 权限码）见《03》各节，或直接读路由表。

## 11.5 前端公共层

| 模块 | 职责 | 关键 API |
| --- | --- | --- |
| `api/http.ts` | HTTP 客户端 | `httpClient.get/post/put/delete/download`；包络解包（code≠200 抛 ApiError）、401 统一登出 |
| `api/session.ts` | 会话存储 | `authSession.save/token/user/clear`；记住登录→localStorage，否则 sessionStorage（键 `linc.*`） |
| `composables/auth.ts` | 会话与菜单 | `COMPONENT_MAP`（菜单组件映射——**新页面必须登记**）、`hasPermission()`、`navGroups`、`refreshUser()` |
| `composables/appearance.ts` | 外观 | `appearance`（skin/theme/density/railCollapsed 响应式 + 持久化）、`useSkin().applySkin()` |
| `themes/index.ts` | 主题注册表 | `SKINS` 元数据（预览色卡驱动主题中心）、`DEFAULT_SKIN`、`skinOf()` |
| `composables/list.ts` | 列表状态机 | `useListPage({query, fetch, exporter})`：查询/重置/分页/导出/请求序号防乱序 |
| `composables/motion.ts` | 动效入口 | `revealCascade / settlePop / floatBarEnter…`；统一尊重减少动效 |
| `composables/toast.ts` | 轻提示 | `pushToast(文案, 'ok'/'danger'/'info')`、`toastError()` |
| `directives/permission.ts` | 权限指令 | `v-permission="'system:user:add'"` 无权限移除元素 |
| `components/business/ListPage.vue` | 列表页模板 | title/desc/table-title/list/columns + 插槽（toolbar/alt 视图/行操作） |
| `components/business/FormDialog.vue` | 统一表单弹窗 | 与 `utils/validate`（required/validate）配套 |
| `components/ui/Icon.vue` | 图标 | `data/icons.ts` 登记的线性图标；菜单 `sys_menu.icon` 取值必须在此登记 |

- 浏览器回归路径：安装向导 → 登录 → 全部页面 → 主题切换（浅/深 × 两主题）→ 低权限账号 403。
