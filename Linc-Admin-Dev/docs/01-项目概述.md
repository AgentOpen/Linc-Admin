# 01 · 项目概述

## 1.1 灵枢中控是什么

**灵枢中控（Linc-Admin）** 是一套面向二次开发的 PHP 统一管理后台模板。它把中后台系统里"每个项目都要写一遍"的部分——认证、菜单与按钮权限、数据权限、组织架构、字典参数、操作审计、代码生成、安装部署——全部做成底座能力，新项目只需在底座上实现业务字段与业务流程。

一句话定位：**兼具设计美学与高效开发的后台模板**。

- **美学**：出厂主题「灵枢青」复刻 DevUI 设计语言（靛蓝主色、冷灰画布、纯白面板、小圆角、轻阴影）；经典主题「珍珠玻璃」提供玻璃拟态质感；浅色 / 深色 / 表格密度全主题通用。
- **高效**：统一响应包络、统一分页、统一权限注解、统一操作日志、统一缓存与导出；新增一个业务模块通常只需要「一张表 + 一份仓储 + 一份服务 + 一页视图」。

## 1.2 系统亮点

- **三步安装**：源码上传、`public` 设为运行目录、访问域名进入四步 Web 向导（环境检查 → 数据库 → 管理员账号 → 执行安装）。安装完成自动生成配置与 64 位 JWT 密钥，落锁防重装。
- **多主题体系**：主题 = CSS 设计令牌覆盖包。主题中心页面即点即换、按浏览器记忆；开发新主题约 30 分钟，不需要触碰任何业务页面（见《05 扩展开发实战》）。
- **权限与数据权限**：菜单 / 按钮两级授权，前后端共用一套权限码；数据范围 ALL / DEPT_AND_CHILD / DEPT / CUSTOM / SELF 五种粒度，超管直通。
- **全程审计**：写接口自动记录操作日志（参数脱敏、耗时、IP 归属），登录事件独立成表；工作台与监控页提供趋势、当日泳道、登录热力与异常聚合。
- **零依赖部署**：默认文件缓存（token、验证码），不强制 Redis；发布包内置 `vendor/`，服务器不需要 Composer。
- **契约级回归**：`tests/api_contract.php` 37 项断言锁定响应包络与业务文案，重构不变形。

## 1.3 技术栈总览

| 分类 | 技术 | 版本 / 说明 |
| --- | --- | --- |
| 运行环境 | PHP | ≥ 8.0（推荐 8.1+），扩展 `pdo_mysql`、`zlib` |
| 路由框架 | Slim 4 | ^4.15，PSR-7 / PSR-15 中间件 |
| 依赖注入 | PHP-DI | ^7.0，装配 Slim 与错误处理器 |
| 数据库 | MySQL | ≥ 5.7，PDO 预处理，会话时区可配（默认 +08:00） |
| 缓存 | 文件（默认）/ Redis | 文件缓存 flock 原子写；Redis 走 Predis ^2.2，键名与 TTL 与缓存语义一致 |
| 认证 | JWT HS256 | 自实现编解码（`hash_hmac`），令牌存缓存，有效期 7200 秒 |
| 密码 | BCrypt | `password_hash` / `password_verify` |
| 前端框架 | Vue | ^3.5，组合式 API |
| 语言 | TypeScript | ~5.7，严格模式 |
| 构建 | Vite | ^6.0，产物输出 `dist/` 并部署到 `public/` |
| 路由 | Vue Router | ^4.5，history 模式，后端动态注册菜单路由 |
| 动效 | GSAP | ^3.15，统一动效入口 `composables/motion.ts` |
| 主题 | CSS 设计令牌 | `data-skin` 主题包 + `data-theme` 明暗 + `data-density` 密度 |

## 1.4 适用场景

- 企业内部管理系统、运营后台、SaaS 控制台的起步底座；
- 需要快速交付"带权限与审计的标准后台"的外包与二次开发项目；
- 想要一套**设计系统完整、可换肤**的 Vue 3 + PHP 全栈参考实现。
