第二步 · 环境检查

自动检测服务器是否满足运行条件，全部通过后进入下一步。

PHP ≥ 8.0（扩展 pdo_mysql） 要求
MySQL ≥ 5.7（推荐 5.7 / 8.0） 要求
伪静态 / URL 重写（宝塔选 laravel5 模板） 需配置
runtime/ 与 config/ 目录可写 要求
Redis（可选，未启用时使用文件缓存） 可选
伪静态配置方法

如果安装向导无法检测环境（提示接口不可达），请先配置伪静态：

· 宝塔用户：网站 → 设置 → 伪静态 → 下拉选择 laravel5 模板 → 保存，然后刷新本页

· Nginx 用户：在站点配置的 location / 中添加：

location / {
    try_files $uri $uri/ /index.php?$query_string;
}

· Apache 用户：确认已启用 mod_rewrite 且站点 AllowOverride 为 All（public/.htaccess 已内置）

第三步 · 数据库连接

填写 MySQL 连接信息；数据库不存在时可勾选自动创建。

第四步 · 管理员账号

设置登录后台的超级管理员；会话与验证码默认使用文件存储，无需安装 Redis。

第五步 · 执行安装

创建数据表、写入初始数据与配置文件，通常几秒内完成。
