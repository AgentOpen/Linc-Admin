# 灵枢中控 Linc-Admin

> 统一管理后台 · 兼具设计美学与高效开发的 PHP 中后台模板

灵枢中控是一套开箱即用的 PHP 中后台管理系统：Web 安装向导三步完成部署，账号、菜单/按钮权限、数据权限、组织架构、字典参数、公告与操作审计开箱即用；前端基于 Vue 3 自有组件库，内置多主题体系（出厂主题「灵枢青」复刻 DevUI 设计语言），代码生成器一键产出业务模块开发骨架。

本仓库提供**三个版本**，功能与数据库结构完全一致，按你的用途选择：

## 三个版本怎么选

| | **[Linc-Admin-Ready](Linc-Admin-Ready/)<br>开箱即用版** | **[Linc-Admin-Portal](Linc-Admin-Portal/)<br>门户一体版** | **[Linc-Admin-Dev](Linc-Admin-Dev/)<br>源码开发版** |
| --- | --- | --- | --- |
| 面向人群 | 直接使用后台 | 要一个带门户首页的网站 | 深度二次开发 |
| 域名根 `/` | 管理后台 SPA | **门户前台（服务端渲染）** | 管理后台 SPA |
| 管理后台入口 | `/` | `/admin` | `/` |
| 前后台联动（公告 / 主题跟随） | 公告仅后台 | ✅ 门户实时跟随 | ✅ 含全部源码 |
| PHP 依赖（vendor/） | ✅ 内置 | ✅ 内置 | 🔧 自行 `composer install` |
| 前端页面 | ✅ 已构建 | ✅ 已构建 | 🔧 自行 `npm run build` |
| 前端源码（frontend/） | ❌ | ❌ | ✅ |
| 开发文档（规范 / 实战 / 附录） | ❌ | ❌ | ✅ |

- **只想用后台** → Ready 版：上传 → 设 `public` 运行目录 → 安装向导。
- **要一个"官网 + 管理后台"的网站**（CRMEB 式体验）→ Portal 版：域名打开是门户前台，后台发公告、换主题，前台实时变。
- **要深度二开**（新增模块、自定义主题、改页面）→ Dev 版，`docs/05-扩展开发实战.md` 含两套完整教程。
- 三版本数据库结构完全一致，可混用：Portal/Ready 上线、Dev 开发。

## 环境要求

| | Ready | Portal | Dev |
| --- | --- | --- | --- |
| PHP | ≥ 8.0（`pdo_mysql`） | ≥ 8.0（`pdo_mysql`） | ≥ 8.0 + Composer |
| MySQL | ≥ 5.7 | ≥ 5.7 | ≥ 5.7 |
| Node.js | 不需要 | 不需要 | ≥ 22（仅构建时） |
| Redis | 可选 | 可选 | 可选 |

## 快速开始

**Ready / Portal 版（三步）**：上传到站点目录 → 运行目录设为 `public/` → 访问域名进入安装向导（伪静态选 `laravel5`）。零基础图文教程：[Ready 版](Linc-Admin-Ready/docs/12-安装教程-从零开始.md) / [Portal 版](Linc-Admin-Portal/docs/12-安装教程-从零开始.md)。

**Dev 版（先构建）**：`composer install` → `npm ci && npm run build` → 产物部署 → 同上安装。教程：[Dev 版 docs/12](Linc-Admin-Dev/docs/12-安装教程-从零开始.md)。

安装完成使用向导中设置的管理员账号登录（默认 `admin / admin123`，生产环境请务必修改）。

## 功能总览

- **认证**：账号密码 + 字符验证码，JWT 会话（HS256，7200 秒），退出即吊销
- **权限**：菜单 / 按钮两级授权，前后端同一套权限码；数据权限五种粒度
- **管理**：用户（列表 / 看板）、角色（矩阵 / 溯源图谱）、菜单（星图）、部门（组织画布）、岗位、字典、参数、**公告**
- **外观**：主题中心多主题切换（灵枢青 / 珍珠玻璃）、浅色 / 深色 / 跟随系统、表格密度；Portal 版前台实时跟随
- **审计**：操作日志、登录日志（趋势 / 泳道 / 热力 / 异常聚合），CSV 导出，敏感参数自动脱敏
- **工具**：代码生成器（PHP 四层骨架 + Vue 页面 + 菜单 SQL）、健康检查
