# 灵枢中控 Linc-Admin

> 统一管理后台 · 兼具设计美学与高效开发的 PHP 中后台模板

灵枢中控是一套开箱即用的 PHP 中后台管理系统：Web 安装向导三步完成部署，账号、菜单/按钮权限、数据权限、组织架构、字典参数与操作审计开箱即用；前端基于 Vue 3 自有组件库，内置多主题体系（出厂主题「灵枢青」复刻 DevUI 设计语言），代码生成器一键产出业务模块开发骨架。

本仓库提供**两个版本**，功能与数据库结构完全一致，按你的用途选择：

## 两个版本怎么选

| | **[Linc-Admin-Ready](Linc-Admin-Ready/)（开箱即用版）** | **[Linc-Admin-Dev](Linc-Admin-Dev/)（源码开发版）** |
| --- | --- | --- |
| 面向人群 | 只想直接使用后台的用户 | 需要二次开发的开发者 |
| PHP 依赖（vendor/） | ✅ 已内置 | 🔧 自行 `composer install` |
| 前端页面 | ✅ 已构建，直接可用 | 🔧 自行 `npm ci && npm run build` |
| 前端源码（frontend/） | ❌ 不包含 | ✅ 包含 |
| 开发文档（规范 / 实战 / 基类附录） | ❌ 不包含 | ✅ 包含 |
| 仓库体积 | 小 | 大（含前端源码） |
| 安装步骤 | 上传 → 建站 → 安装向导 | 构建 → 上传 → 建站 → 安装向导 |

- **只想用后台** → 用 Ready 版：上传服务器、设 `public` 为运行目录、访问域名即进安装向导。
- **要做二开**（新增业务模块、自定义主题、改页面）→ 用 Dev 版：`docs/05-扩展开发实战.md` 含新增业务模块与 30 分钟主题开发两套完整教程。
- 两个版本可混用：用 Ready 版上线，用 Dev 版开发，数据库通用。

## 环境要求

| | Ready | Dev |
| --- | --- | --- |
| PHP | ≥ 8.0（`pdo_mysql`） | ≥ 8.0（`pdo_mysql`）+ Composer |
| MySQL | ≥ 5.7 | ≥ 5.7 |
| Node.js | 不需要 | ≥ 22（仅构建时） |
| Redis | 可选 | 可选 |

## 快速开始

**Ready 版（三步）**：上传到站点目录 → 运行目录设为 `public/` → 访问域名进入安装向导。零基础图文教程：[Linc-Admin-Ready/docs/12-安装教程-从零开始.md](Linc-Admin-Ready/docs/12-安装教程-从零开始.md)。

**Dev 版（先构建）**：`composer install` → `npm ci && npm run build` → 产物部署 → 同上安装。教程：[Linc-Admin-Dev/docs/12-安装教程-从零开始.md](Linc-Admin-Dev/docs/12-安装教程-从零开始.md)。

安装完成使用向导中设置的管理员账号登录（默认 `admin / admin123`，生产环境请务必修改）。

## 功能总览

- **认证**：账号密码 + 字符验证码，JWT 会话（HS256，7200 秒），退出即吊销
- **权限**：菜单 / 按钮两级授权，前后端同一套权限码；数据权限五种粒度（全部 / 本部门及下级 / 本部门 / 自定义 / 仅本人）
- **管理**：用户（列表 / 看板）、角色（矩阵 / 溯源图谱）、菜单（星图）、部门（组织画布）、岗位、字典、参数
- **外观**：主题中心多主题切换（灵枢青 / 珍珠玻璃）、浅色 / 深色 / 跟随系统、表格密度
- **审计**：操作日志、登录日志（趋势 / 泳道 / 热力 / 异常聚合），CSV 导出，敏感参数自动脱敏
- **工具**：代码生成器（PHP 四层骨架 + Vue 页面 + 菜单 SQL）、健康检查
